# 身份与访问管理（IAM）

身份与访问管理（Identity and Access Management，IAM）负责自然人和服务身份、认证、会话、角色、权限、策略与授权关系。术语来源见 [NIST IAM Glossary](https://csrc.nist.gov/glossary/term/Identity_and_access_management)。运行时必须获得可信且可验证的主体和租户上下文。

不负责套餐权益、菜单内容或业务数据。

详细范围、用户需求、系统需求和验收场景见 [IAM 模块需求](../../docs/requirements/modules/iam.md)。
