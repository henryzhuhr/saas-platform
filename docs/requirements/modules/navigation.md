# 导航管理模块需求

| 属性 | 内容 |
| --- | --- |
| 模块 | Navigation |
| 工程边界 | `platform/navigation` |
| 文档状态 | 草案，待产品、前端与架构评审 |
| 主要需求编号 | `UR-NAV-*`、`SR-NAV-*` |

## 1. 目标与边界

Navigation 模块根据应用状态、租户开通、用户权限、租户权益和租户配置生成稳定、可解释的页面入口。它管理用户体验，不承担后端安全授权。

负责：

- 应用入口、页面导航节点、层级、排序和展示元数据。
- 导航条件声明和最终可见性计算。
- 租户级隐藏、排序等受控定制。
- 管理预览、原因解释和运行时派生视图。

不负责：

- 网络流量转发、服务版本灰度和 API 网关配置。
- 业务 API 的最终权限、权益和租户隔离执行。
- 业务应用页面内容和页面内按钮级业务逻辑。
- 通过显示入口授予任何权限或权益。

## 2. 参与角色与依赖

| 参与方 | 主要职责 |
| --- | --- |
| 租户成员 | 查看当前租户可访问的应用和页面入口 |
| 租户管理员 | 在允许范围内隐藏、排序或配置本租户入口 |
| 业务应用负责人 | 通过应用清单声明导航节点和条件 |
| 平台管理员 | 管理平台级入口、冲突和展示策略 |
| Application 模块 | 提供应用状态、版本和租户开通关系 |
| IAM 模块 | 提供主体权限和成员关系版本 |
| Entitlement 模块 | 提供租户最终权益版本 |
| Audit 模块 | 记录导航配置变更和管理预览 |

## 3. 用户需求

| 编号 | 优先级 | 用户需求 | 详细验收要点 |
| --- | --- | --- | --- |
| UR-NAV-001 | P0 | 作为用户，我希望登录后看到稳定的应用和导航入口。 | 返回当前租户适用、顺序稳定、无循环和无孤立节点的树；重复读取在依赖未变化时结果一致。 |
| UR-NAV-002 | P0 | 作为管理员，我希望导航入口关联权限和权益。 | 可见性同时考虑应用状态、租户开通、成员权限、租户权益和租户配置，任一必要条件不满足即隐藏。 |
| UR-NAV-003 | P0 | 作为租户管理员，我希望定制本租户导航。 | 租户定制只能隐藏、排序或修改允许的展示属性，不能显示平台或应用已禁用的入口。 |
| UR-NAV-004 | P1 | 作为管理员，我希望预览指定用户的最终导航。 | 预览明确使用的用户、租户、时间和依赖版本，并解释每个节点显示或隐藏原因。 |

## 4. 系统需求

| 编号 | 优先级 | 系统行为 | 主要来源 |
| --- | --- | --- | --- |
| SR-NAV-001 | P0 | 系统应管理应用入口、导航节点、层级、稳定排序键、页面地址和展示元数据。 | `UR-NAV-001` |
| SR-NAV-002 | P0 | 导航节点可关联必要权限、权益、应用状态、租户开通和租户配置条件。 | `UR-NAV-002`、`UR-NAV-003` |
| SR-NAV-003 | P0 | 系统应计算当前主体和租户的最终导航，并返回稳定有序、带结果版本的树。 | `UR-NAV-001`、`UR-NAV-002` |
| SR-NAV-004 | P0 | 最终导航不得包含循环、孤立节点、不可访问父节点或重复稳定标识。 | `UR-NAV-001` |
| SR-NAV-005 | P1 | 系统应支持基于明确上下文的预览，并提供不泄露敏感策略的节点解释。 | `UR-NAV-004` |
| SR-NAV-006 | P0 | 导航及其依赖状态变化必须在规定传播窗口内使相关派生结果失效。 | `UR-NAV-001`、`UR-NAV-002`、`UR-NAV-003` |

## 5. 计算规则与不变量

基础可见性规则：

```text
导航可见
= 应用版本允许展示
AND 租户已开通应用
AND 用户拥有全部必要权限
AND 租户拥有全部必要权益
AND 租户未隐藏入口
AND 父级节点可见或允许作为容器保留
```

- 导航条件只决定展示，不产生权限、权益或应用开通事实。
- 未知条件、依赖读取失败或版本不完整时，默认不展示受影响入口。
- 节点稳定标识一旦发布不能复用为不同页面语义。
- 兄弟节点排序使用显式排序值和稳定标识作为并列规则，避免结果抖动。
- 子节点可见而父节点仅为容器时，可以保留无直接页面的父节点；规则必须统一。
- 外部链接、内部页面地址和应用根入口需要不同类型，不能通过任意 URL 混用。

## 6. 租户定制与展示要求

- 租户管理员只能修改应用声明允许覆盖的展示字段。
- 租户定制不能修改权限、权益条件、应用所有权和目标应用身份。
- 隐藏父节点时默认隐藏全部后代；重新显示父节点不能自动绕过后代自身条件。
- 本地化文本应使用稳定文本键和可选默认值，不把翻译内容作为节点标识。
- 图标、徽标和展示资源必须限制类型、尺寸和可信来源，避免成为脚本或跟踪注入入口。
- 导航响应应包含版本或校验标识，支持客户端缓存和变化检测。

## 7. 缓存与传播要求

- 导航结果缓存键至少区分主体授权版本、租户、应用开通版本、权益版本和租户配置版本。
- 权限撤销、权益撤销、应用暂停和租户停用应优先收窄结果。
- 消费方发现依赖版本缺口时必须重新同步，不能无限期返回旧入口。
- 预览结果必须标识是否使用尚未生效的候选配置，不能与生产结果混淆。
- 大租户导航读取不能逐节点远程调用权限或权益服务，应使用批量或版本化运行时视图。

## 8. 验收场景

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC-NAV-001 | 用户具备应用、权限、权益和租户开通条件 | 返回入口及完整可见父链，排序稳定且含结果版本 |
| AC-NAV-002 | 用户缺少权限但手工访问页面地址 | 导航不展示入口；业务 API 仍独立拒绝请求 |
| AC-NAV-003 | 租户权益被撤销 | 受影响入口在传播窗口内消失，无关入口保持稳定 |
| AC-NAV-004 | 租户管理员隐藏父节点 | 父节点及后代按统一规则隐藏，不改变任何后端授权 |
| AC-NAV-005 | 清单提交循环或孤立节点 | 生效前校验失败，并返回涉及的节点路径 |
| AC-NAV-006 | 两个节点排序值相同 | 使用稳定次序规则返回，不因实例或读取时间改变顺序 |
| AC-NAV-007 | 管理员预览被暂停用户的导航 | 返回空或受限结果，并解释成员或身份状态原因 |
| AC-NAV-008 | 权益依赖暂时无法确认 | 受影响入口安全隐藏，响应标识降级或依赖状态 |

## 9. 待确认事项

- 首批导航节点类型、页面集成模式和跨应用跳转体验。
- 租户允许覆盖的字段、最大树深度、节点数量和本地化语言范围。
- 是否需要用户个人收藏、最近访问和个性化排序；这些是否属于独立体验能力。
- 导航解释对租户管理员和普通用户分别展示到什么粒度。
- Portal、Console 和业务应用是否共享同一导航契约或使用不同视图。
