# 需求文档地图

本目录描述产品目标、用户场景、系统能力、约束和验收标准。

## 文档

- [项目用户需求](user-requirements.md)：目标用户、核心旅程、用户故事、优先级和范围边界。
- [项目系统需求](system-requirements.md)：系统边界、功能需求、数据要求、非功能需求和系统验收标准。
- [项目术语表](glossary.md)：统一身份、租户、授权、权益、路由和可靠性术语。
- [规范依据矩阵](standards-and-evidence.md)：映射安全、可靠性和多租户需求到权威标准及行业指南。

## 变更顺序

1. 先在用户需求中确认角色、目标、优先级和业务验收标准。
2. 再将用户需求映射到带编号的系统需求。
3. 更新相关架构、ADR、公开契约和测试。
4. 保留已被引用的需求编号；废弃需求应指向替代项。
