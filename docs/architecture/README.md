# 架构文档地图

本目录维护系统结构、模块边界和重大技术决策。

## 文档

- [架构总览](../../ARCHITECTURE.md)：系统上下文、逻辑架构、领域模块、核心流程、安全、部署和演进路线。
- [项目结构与模块边界](project-structure.md)：Monorepo 目录、领域/部署/契约边界、依赖规则和规模约束。
- [IAM 实现说明导航](iam-implementation.md)：指向 IAM 独立项目内的范围、依赖、验证及待完成事项正文。

## 决策记录

- [ADR 索引](decisions/README.md)：重大、跨模块或难以撤销的架构决策。

## 使用规则

- 全局架构变化先更新根 `ARCHITECTURE.md`。
- 目录和模块依赖变化同步更新 `project-structure.md`。
- 具体技术选择通过 ADR 记录背景、方案、影响和迁移方式。
- 架构文档必须引用相关需求编号或明确说明其需求来源。
